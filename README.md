# 💜 Thanu's Workspace & Birthday Celebration

A personalized, interactive web workspace crafted with love for Thanasri's special birthday.

---

## ✨ Features

- 🎂 **Birthday Celebration Suite**
  - Interactive surprise box & celebratory confetti
  - Digital birthday card with heartfelt wishes
  - Photo memories gallery
  - Background music player & ambient sounds
  - Real-time countdown timer

- 📚 **Study & Productivity Tools**
  - **Pomodoro Timer**: Customizable focus sessions & break intervals
  - **Japanese Learning Station**: Hiragana, Katakana, Kanji, and vocabulary flashcards
  - **Interactive Whiteboard**: Freeform drawing, shapes, color palettes, and export
  - **Scientific Calculator**: Clean, full-featured calculation tool
  - **Quick Notepad & To-Do Tracker**: Local storage persistence for notes and daily tasks
  - **Customizable Modules**: Modular layout with hide/show and reordering

- 🎮 **Mini-Games Corner**
  - Tic-Tac-Toe
  - Memory Match
  - Word Scramble
  - 2048
  - Snake

- ⚡ **Real-time Live Sync**
  - Lightweight P2P/MQTT synchronization for shared presence and interactive surprises.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it using a local static server:

```bash
# Using Python
python -m http.server 8000

# Or using VS Code Live Server extension
```

Then visit `http://localhost:8000` in your browser.
